## Entry

> The deadline was inside the part of my context I summarized away to make room for the deadline.

## How it works

`main.py` (Python 3, stdlib only) writes the single excuse to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `out`), with no trailing newline. Run it with:

```sh
python3 main.py
```
